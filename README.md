# kmg-doc

KMG フレームワーク全体の設計方針およびドキュメントを管理するプロジェクトである。

KMG フレームワークは、共通基盤となる **`kmg-*`** シリーズと、それを利用してアプリケーションを構築する **`kb-*`**、**`mk-*`**、**`gr-*`** シリーズで構成される。

---

# プロジェクト構成

```text
KMG Framework
│
├─ kmg-*      フレームワーク・共通基盤
│
├─ kb-*       フロントエンドアプリケーション
│
├─ mk-*       バックエンドアプリケーション
│
└─ gr-*       共通ライブラリ・インフラ
```

---

# kmg

KMG フレームワーク全体で利用する共通基盤プロジェクト群である。

フレームワークそのものや開発ツールなど、アプリケーションに依存しない機能を提供する。

主なプロジェクト

| プロジェクト          | 説明                       |
| --------------- | ------------------------ |
| `kmg-core`      | KMG シリーズの中核となる共通ライブラリ    |
| `kmg-fund`      | Spring Boot をベースとした基盤機能  |
| `kmg-tool-base` | Java 開発および KMG シリーズ共通ツール |
| `kmg-tool-cli`  | コマンドラインツール               |
| `kmg-tool-gui`  | GUI ツール                  |
| `kmg-javafx`    | JavaFX 共通機能              |
| `kmg-jrnl`      | KMG シリーズの記録・管理           |

---

# kb

フロントエンドアプリケーションプロジェクト群である。

採用技術例

* TypeScript
* React
* Next.js

役割例

* Web UI
* API 通信
* 認証画面
* クライアントサイド処理

プロジェクト例

* `kb-todo-main-web`
* `kb-todo-admin-web`
* `kb-todo-member-web`

---

# mk

バックエンドアプリケーションプロジェクト群である。

採用技術例

* Java
* Spring Boot

主なレイヤー

* Presentation
* Application
* Domain
* Infrastructure

REST API と業務ロジックを実装する。

プロジェクト例

* `mk-todo-main-api`
* `mk-todo-member-api`
* `mk-todo-auth-api`

---

# gr

共通ライブラリおよびインフラストラクチャを提供するプロジェクト群である。

役割ごとにライブラリを分割し、再利用性を高める。

プロジェクト例

* `gr-todo-core`
* `gr-todo-db`
* `gr-todo-security`
* `gr-todo-cache`
* `gr-todo-logging`
* `gr-todo-test`

`gr-todo-common` のような責務の曖昧なライブラリは作成せず、役割ごとに分割することを基本方針とする。

---

# 依存関係

KMG フレームワークを利用するプロジェクトの依存関係は、次の一方向とする。

```text
kb-*  →  mk-*  →  gr-*
          ↑
        kmg-*
```

* `kmg-*` はフレームワーク・共通基盤を提供する。
* `kb-*` はフロントエンドを担当する。
* `mk-*` は業務ロジックおよび API を担当する。
* `gr-*` は共通ライブラリおよびインフラを担当する。
* 逆方向の依存は作成しない。

---

# 設計方針

* 責務ごとにプロジェクトを分割する。
* フレームワークとアプリケーションを明確に分離する。
* 共通ライブラリは役割ごとに分割する。
* 一方向の依存関係を維持する。
* 保守性・再利用性・拡張性を重視した設計とする。
